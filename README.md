# Domestic Logistics Cost Saving Project

## Project Overview

This project focuses on analyzing domestic logistics costs and identifying opportunities to reduce transportation expenses.

The analysis evaluates Pricol's domestic logistics costs from April 2022 to January 2023 and identifies potential cost-saving opportunities.

## Key Areas Analyzed

- Inbound and outbound logistics
- Plant-wise freight costs
- Top 20 inbound and outbound transportation values
- Shipment consolidation
- Transportation mode optimization
- Milk Run methodology
- Route optimization
- Vehicle utilization

## Key Findings

The total estimated annual freight across the analyzed plants was ₹2,233.69 lakhs.

Potential savings were estimated at:

- 20% savings: ₹446.74 lakhs
- 30% savings: ₹670.11 lakhs
- 40% savings: ₹893.47 lakhs

## Cost Reduction Strategies

1. Localization
2. Shipment consolidation
3. Reducing the number of shipments
4. Full truck utilization
5. Milk Run transportation
6. Transportation mode optimization
7. Route optimization
